# Blocs and Swings dashboard (simple version)

Two pages:
- **Voting blocs** (Q1): world map and PCA map of the blocs in any decade
- **Predict a resolution** (Q2, Q3): predicted vs actual votes, and the swing countries

Run on your laptop:

    pip install -r requirements.txt
    streamlit run app.py

Keep `app.py` and the `app_data` folder together. The files in `app_data` are made by section 9 of `Blocs_and_Swings_Simple.ipynb`.
